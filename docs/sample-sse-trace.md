# Sample live SSE event trace

Captured against a real running `uvicorn` server (not a test harness) for
the canonical example prompt from this README, confirming the full agent
graph streams live progress end to end, in order, over `GET
/api/trips/{id}/stream`.

```
event: agent_started      requirement_extractor  Understanding your trip request...
event: agent_completed    requirement_extractor  Extracted your trip requirements.
event: agent_started      missing_info_checker   Checking whether anything critical is missing...
event: agent_completed    missing_info_checker   All required trip details are present.
event: agent_started      destination_research   Researching destinations that fit your preferences...
event: tool_started       destination_research   Searching the web for travel context on Japan...
event: search_result      destination_research   Found 3 supporting source(s).
event: agent_completed    destination_research   Chosen destination: Japan
event: agent_started      flight_research        Searching flight options...
event: tool_completed     flight_research        Found 4 flights, selected 3.
event: agent_started      hotel_research         Comparing hotels...
event: tool_completed     hotel_research         Found 5 hotels, selected 3.
event: agent_started      food_research          Finding restaurants and food experiences...
event: agent_started      places_research        Finding attractions and experiences...
event: tool_completed     food_research          Found 7 restaurants, ranked 7.
event: tool_completed     places_research        Found 18 places, ranked 14.
event: agent_started      transportation         Optimizing local and airport transportation...
event: agent_completed    transportation         Transportation plan ready.
event: agent_started      weather_season         Checking weather and seasonality...
event: tool_completed     weather_season         Weather outlook ready for 8 day(s).
event: agent_started      budget_optimizer       Building the budget and checking it against your limit...
event: budget_updated     budget_optimizer       Estimated total: 269489 INR.
event: agent_started      itinerary_generator    Assembling your day-by-day itinerary...
event: agent_completed    itinerary_generator    Drafted a 8-day itinerary.
event: agent_started      critic                 Reviewing the itinerary for problems...
event: critic_result      critic                 Itinerary approved -- no blocking issues found.
event: completed          finalize               Itinerary approved by the critic.
```

Note `flight_research`/`hotel_research` firing back-to-back and
`food_research`/`places_research` interleaving -- that's the two parallel
research branches (see `docs/agent-architecture.md`) actually running
concurrently, not a scripted sequence.
